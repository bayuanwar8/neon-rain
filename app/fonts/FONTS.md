# Fonts

Three font files from the Google Fonts repository, unchanged, under `app/fonts/`:

- **Anton** (`Anton-Regular.ttf`) — SIL Open Font License 1.1. Used for the
  chrome title, name tags, quote bar, billing block and UI headings.
  License: `OFL-anton.txt`.
- **Caveat** (`Caveat.ttf`) — SIL Open Font License 1.1. Used for the neon
  script subtitle. License: `OFL-caveat.txt`.
- **Playfair Display** (`PlayfairDisplay.ttf`) — SIL Open Font License 1.1.
  Used for the Rain Serif title style. License: `OFL-playfair.txt`.

All three are original Google Fonts designs, freely licensed for this use.
